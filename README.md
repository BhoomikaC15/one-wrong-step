# 🐰 One Wrong Step

A fun math adventure game where every correct answer moves you closer to the finish line... but one wrong answer can end the journey!

## 🎮 About the Game

**One Wrong Step** is a browser-based educational game that turns math practice into a mini adventure.

Guide a brave little rabbit across **10 steps** to reach the finish flag. To move forward, players must correctly solve randomly generated math questions. Every correct answer advances the rabbit one step closer to victory.

However, there's a catch:

> ❌ One wrong answer = Game Over

Players must carefully solve each problem and make it all the way to Step 10 without making a mistake.

---

## ✨ Features

- 🐰 Cute rabbit character progression
- 🎯 10-step challenge system
- ➕ Addition problems (up to 3-digit numbers)
- ➖ Subtraction problems (up to 3-digit numbers)
- ✖️ Multiplication problems (up to 2-digit numbers)
- ➗ Division problems (dividend up to 3 digits, divisor up to 15)
- 🔥 Streak counter to track consecutive successes
- 🚩 Finish line goal
- 📱 Clean and colorful user interface
- 🎲 Randomized questions for replayability

---

## 🕹️ How to Play

1. Start at Step 1.
2. Read the math question.
3. Enter your answer.
4. Submit to take the next step.
5. A correct answer moves the rabbit forward.
6. Reach Step 10 to win.
7. Be careful:
   - ✅ Correct Answer → Keep moving
   - ❌ Wrong Answer → Fall and restart

## 🎯 Educational Purpose

The game helps players practice:

- Mental arithmetic
- Quick decision making
- Basic mathematics
- Accuracy under pressure

By combining learning with gameplay, math becomes more engaging and rewarding.
